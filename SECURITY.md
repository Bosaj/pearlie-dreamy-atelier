# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| `1.2.x` | :white_check_mark: |
| `< 1.2` | :x: |

## Reporting a Vulnerability

If you discover a security issue in **Pearlie Handcrafted × Little Calm Corner Digital Maison**:

- **Do not** open a public GitHub issue for anything exploitable.
- Report it privately to the repository administrators ([@Bosaj](https://github.com/Bosaj) at `oussousselhadji@gmail.com` or [@IhsaneFathi](https://github.com/IhsaneFathi)) via a private GitHub security advisory.
- Include clear steps to reproduce and the potential impact.

Never commit secrets or private API keys. Environment variables belong in a git-ignored `.env` file; see `.env.example` for documented public configuration variables.
