# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

## Our Pledge

In the spirit of **Pearlie Handcrafted (`@_pearlie.dreamy`)** and **Little Calm Corner (`@__little.calmcorner`)** — *"a gentle corner for peaceful minds"* — we pledge to make participation in our project a harassment-free, welcoming, and respectful experience for everyone.

## Standards

- Be respectful, constructive, and kind in all discussions, code reviews, and issues.
- No harassment, discrimination, or personal attacks.
- Assume good faith and keep technical discussions focused on craft and quality.

## Enforcement

Report unacceptable behavior privately to the repository co-owners ([@Bosaj](https://github.com/Bosaj) or [@IhsaneFathi](https://github.com/IhsaneFathi)) via GitHub private message or security advisory.
